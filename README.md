# leaf

A light, fast, keyboard-first text and Markdown editor for macOS, written in Rust.

Open a folder, walk its tree with the arrow keys, copy paths in one keystroke,
and read Markdown and code with syntax highlighting. An editor, not an IDE.

Work in progress: nothing to run yet.
